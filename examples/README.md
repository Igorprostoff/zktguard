# examples

Reference Mini Apps demonstrating SDK integration. Each example is self-contained and uses `@zktguard/sdk` directly with no duplicated logic.

Planned examples for v0.1:

- `quest-gate` — credential-gated quest reward
- `airdrop-gate` — credential-gated airdrop claim
- `dao-vote` — vote weight conditional on credential ownership

Each example carries its own README with a five-minute setup guide and is exercised end-to-end against TON testnet before tagging.
